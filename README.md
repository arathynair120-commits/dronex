AeroSentinel is an AI-powered UAV flight intelligence platform designed to enhance aerial situational awareness by combining real-time object detection with flight-aware analysis. Built using the AU-AIR multimodal UAV dataset and YOLO-based computer vision, the system identifies and tracks objects in aerial environments while analyzing their position, movement, persistence, and proximity to the UAV’s projected flight corridor. By integrating visual perception with telemetry and flight-path information, AeroSentinel goes beyond conventional object detection to estimate the relevance of detected objects as potential flight hazards. The platform transforms raw aerial imagery and flight data into interpretable risk intelligence, helping UAV operators better understand their surroundings and make proactive, context-aware flight-safety decisions. # drone
